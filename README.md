# PetCare 宠物店管理系统

数据库实验课程项目，贯穿第1—17周。

## 一、项目范围

PetCare 宠物店管理系统，包含以下核心业务：

- 商品管理
- 库存管理
- 会员管理
- 商品销售与订单管理
- 订单明细管理
- 会员积分管理
- 宠物服务管理
- 服务预约与消费管理
- 员工及经营角色管理

## 二、业务角色

| 角色       | 主要职责                                                       |
| ---------- | -------------------------------------------------------------- |
| 店长       | 门店整体经营、商品与库存管理、员工管理、经营数据查看、补货管理 |
| 店员       | 接待顾客、商品销售、订单处理、会员办理、宠物服务登记           |
| 会员/顾客  | 购买商品、预约宠物服务、参与会员积分活动                       |
| 系统管理员 | 系统账号、角色和权限维护                                       |

## 三、业务流程

1. 顾客到店
2. 判断是否会员：是则查询会员信息，否则可注册会员
3. 选择商品或宠物服务
4. 购买商品：查询库存 → 创建订单 → 添加订单明细 → 计算金额 → 支付 → 扣减库存
5. 预约服务：选择服务项目 → 确认预约时间 → 创建服务预约 → 完成服务 → 支付
6. 记录消费信息
7. 计算并更新会员积分
8. 完成交易

## 四、核心业务对象

| 业务对象 | 说明                               |
| -------- | ---------------------------------- |
| 商品     | 宠物食品、宠物用品等可销售商品     |
| 库存     | 记录商品当前库存及库存变化         |
| 订单     | 记录一次完整的商品或服务消费       |
| 订单明细 | 记录订单中具体购买的商品           |
| 会员     | 记录会员基本信息及会员积分         |
| 员工     | 记录店长、店员等工作人员信息       |
| 宠物服务 | 记录宠物店提供的服务项目           |
| 服务预约 | 记录会员或顾客的服务预约及消费信息 |

## 五、SQL 脚本执行顺序

按以下顺序执行 `sql/` 目录下的脚本：

1. `sql/01_create_database.sql` —— 创建数据库
2. `sql/02_create_tables.sql` —— 创建数据表
3. `sql/03_insert_data.sql` —— 插入样例数据
4. `sql/04_crud.sql` —— 增删改查演示
5. `sql/05_query.sql` —— 多表查询
6. `sql/06_view.sql` —— 统计视图
7. `sql/07_constraint.sql` —— 完整性约束
8. `sql/08_role.sql` —— 角色权限

## 六、复现步骤

1. 安装 SQL Server 2022 Express 和 SSMS。
2. 打开 SSMS，连接本地数据库。
3. 新建查询，按顺序执行 `sql/` 目录下的脚本。
4. 查看 `result/` 目录中的截图，核对执行结果。
5. 如要从空库复现，先执行：

```sql
IF DB_ID('PetCareDB') IS NOT NULL
    DROP DATABASE PetCareDB;
GO
```
