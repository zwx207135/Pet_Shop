# 第一阶段报告：数据库初建与 CRUD

## 一、经营场景与业务流程

详见 `docs/第1周_业务需求分析.md`。

PetCare 宠物店管理系统，主要角色包括店长、店员、会员/顾客、系统管理员。核心业务包括商品销售、库存管理、会员积分、宠物服务预约。

| Orders | 订单表 |
